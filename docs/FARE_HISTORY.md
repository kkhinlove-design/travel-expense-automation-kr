# 날짜별 버스 운임

- 적용 기준: 가는 길은 `startAt`, 오는 길은 `endAt`의 날짜. `effective_from` 이상, `effective_until` 미만인 이력 중 가장 최근 시작일을 사용한다.
- 기존 28개 요금은 보존한다. 확인된 인상 후 요금 20개는 2026. 10. 01.부터 적용한다. 근거와 확인 대기 8개 노선은 `config/bus-fare-revision-2026-10-01.json`에 기록한다.
- 10월 이후 금액이 미확인인 노선에는 종료된 과거 금액을 대신 적용하지 않는다. 화면에서 확인된 요금을 직접 입력하거나 관리자 화면에서 적용 시작일을 지정해 등록한다.
- 전주→군산 예시: 2026. 09. 30. 왕복 13,200원, 2026. 10. 01. 왕복 14,400원, 09. 30. 출발·10. 01. 복귀 13,800원.
- 날짜를 수정하면 기준표 운임을 재계산한다. 직접 입력한 금액은 방향별로 보존한다. 저장된 출장 기록은 편집 화면에 불러올 때 재계산하며 자동으로 덮어쓰지 않는다.
- 관리자 업로드는 같은 노선·같은 적용 시작일만 갱신한다. 적용일을 생략한 업로드는 거부한다. Google 불러오기는 기본 운임 시트의 도내·도외 버스 탭을 읽으며, 수집일을 적용일로 임의 해석하지 않는다.
- 배포 순서: 날짜 열 마이그레이션 → 관리자 Edge Function → 웹 코드 → `supabase/data/bus_fare_revision_20261001.sql`. 데이터 적용문은 기존 28개 및 20개 대응 금액의 일치를 확인한 뒤 실행한다.
- 검증: 자동 테스트 103건, 운영 빌드, 가상 출장 브라우저에서 인상 전·후·경계 왕복·역변경·방향별 직접 입력 보존, 데스크톱·모바일 확인. 브라우저 검증은 가상 사용자와 API 응답을 사용했고 운영 개인 출장자료는 수정하지 않았다.
