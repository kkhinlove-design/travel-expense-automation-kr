# 작업 인수인계

- 마지막 작업: 2026. 08. 19. 직원 출장 화면의 운임 설정 메뉴·개인 운임 편집 기능을 제거하고 공용 운임 조회만 유지했으며, 변경 API를 차단하고 관리자 화면의 공용 운임 설정 영역으로 관리 경로를 일원화해 73개 테스트와 프로덕션 빌드를 통과
- 다음 할 일: Vercel 운영 배포 후 일반 직원 화면에 운임 설정이 노출되지 않고 관리자 `/admin#fare-settings`에서 공용 운임 엑셀 등록이 유지되는지 데스크톱·모바일 스모크 테스트
- 주의사항: 이전 `travel_fare_presets` 개인 운임 데이터는 삭제하지 않고 보존하되 현재 자동 계산에서는 제외하며, 공유 Supabase의 전체 `db push`와 출장 앱 밖 `billing` Function 변경은 별도 영향 검토 없이 실행 금지
