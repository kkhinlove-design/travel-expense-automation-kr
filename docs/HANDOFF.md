# 작업 인수인계

- 마지막 작업: 2026. 11. 01. 내 출장대장을 10건씩 페이지로 표시(이전·번호·다음, 필터별 적용). 같은 날 비교표 기준 운임 추가 반영(운영 DB 106행)과 "운임 확인 필요" 경고 추가. 테스트·운영 빌드·운영 화면 데스크톱/모바일 검증.
- 다음 할 일: 군산→광주·대구서부·울산·포항, 익산→광주·서울의 2026. 10. 01. 이후 요금 확인 후 관리자 화면에서 적용 시작일과 함께 등록. 저장된 2026. 10. 06. 군산→전주 출장 1건(6,600원)은 담당자 재저장·정산 정정 필요. 세부 근거는 docs/FARE_HISTORY.md 참조.
- 주의사항: 미확인 인상 후 금액을 과거 요금으로 대체하지 않음. 직접 입력은 방향별 보존, 기존 출장 기록은 불러올 때 재계산하며 자동 덮어쓰기하지 않음. 배포 시 스키마·Edge Function·웹 반영 후 supabase/data/bus_fare_revision_20261001.sql 적용. 출장지에 "인천"만 적으면 인천공항 요금이 자동 적용되며(단어 부분일치), 여비 계산 화면에 "운임 확인 필요" 경고를 띄움. 양방향 직접 입력 시 사라짐. 대장 API는 최근 200건까지만 반환하므로 200건을 넘으면 집계·페이지에 옛 기록이 빠짐. 개인정보·환경설정·검증 산출물은 Git 제외.
