- 마지막 작업: 2026. 08. 19. PDF 표의 같은 높이에 있는 출장목적·기간·출장지·비고가 한 줄로 섞이는 사례를 좌표 기반 열/행 파싱으로 수정하고, 글자 단위 기관명도 먼저 묶어 부서·직위 경계를 보존하도록 보강했으며 70개 테스트와 프로덕션 빌드를 통과
